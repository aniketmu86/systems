// Operational Transformation

Proprietary Software Ecosystem

To protect IP and eliminate cloud-dependency friction in restricted enterprise environments, I independently architected a suite of zero-install desktop media applications.

AVT Suite (Aniket's Video Tools)

PythonPyTorchFFmpeg

A local, offline media-processing workstation replacing command-line FFmpeg operations, manual audio normalization, and third-party subtitle converters.

  • Integrates DeepFilterNet3 and PyTorch natively for local, AI-assisted audio denoising and EBU loudness normalization.
  • Handles HDR-to-SDR tone mapping, video compression, and multi-format subtitle conversion (`.srt`, `.vtt`, `.ass`, `.stl`).
  • Delivered as a standalone Nuitka `.app` bundle requiring zero end-user runtime installations (no Python, pip, or Homebrew needed).

Global RMS

PythonSQLiteCustomTkinter

A local-first desktop Review Management System built to replace chaotic spreadsheet/email-based QC with a governed, offline package loop.

  • Establishes traceability across a 14-step review chain: project → processor QC → reviewer feedback → resolution.
  • Uses a SQLite persistence layer with strict foreign-key enforcement and frame-aware timecode validation.
  • Employs a non-destructive filesystem design that provisions missing task folders without mutating existing assets.

Subtitle Studio v6

PythonAVFoundationMPV

A stateful, cross-platform video editing tool for loading media, frame-accurate cue timing, section management, and multi-format deliverable export.

  • Consolidates subtitle editors, video players, and audio-denoise utilities into one thread-safe GUI.
  • Features a custom ASS rendering engine for merged backgrounds and precision alignment previewing.
  • Safe macOS architecture utilizes AVFoundation for timing, passing BGRA frames through `AVPlayerItemVideoOutput` directly to the UI.

OmniPlayer v0.7.0

Swift 6AVKitAppKit

A native Apple Silicon macOS desktop player built to eliminate the manual identification and conversion of unsupported Apple codecs.

  • Automatically probes and transparently converts non-native media (like QuickTime `qtrle`) via bundled FFmpeg binaries.
  • Preserves crucial alpha transparency by converting to ProRes 4444 seamlessly in the background.
  • Eliminates multi-step review processes, replacing external transcoding workflows with a single drag-and-drop operation.
